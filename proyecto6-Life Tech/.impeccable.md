# Life Tech · Design Context

## Design Context

### Users
Mixto: gamers competitivos (18-28, FPS/MOBA, rendimiento), entusiastas de setups (estética + performance, battlestations), y creators/streamers (calidad audiovisual, monetización). El denominador común: todos viven la tecnología como identidad, no solo como herramienta. Navegan en la noche, desde escritorios oscuros con RGB.

### Brand Personality
**Rápida · Potente · Auténtica**

Tono: directo y confiante. Sin florituras innecesarias. Sabe lo que vende y a quién. Como Razer pero con rojo propio: agresivo sin ser caricaturesco.

### Aesthetic Direction
- **Referencia principal**: razer.com — fondo muy oscuro, elementos que emergen del negro, tipografía de impacto, producto siempre al centro
- **Paleta**: negro profundo (#050506) + rojo Life Tech (#ef2b2b) como único acento caliente. El violeta (#a855f7) para features de IA. Amarillo (#ffe600) solo para indicadores live.
- **Fondos**: partículas animadas sutiles (puntos que se mueven lentamente como constelaciones) + reveal dramático al hacer scroll (elements fade+slide desde abajo)
- **Diferenciador**: los fondos no son estáticos — viven. Las tarjetas reaccionan físicamente al hover con glow rojo. El scroll tiene momentum cinematográfico.
- **Anti-referencia**: nada de glassmorphism decorativo, nada de gradientes de texto, nada de cards genéricas con sombra gris.

### Design Principles
1. **El producto es el héroe** — fondos y efectos amplifican el producto, nunca compiten con él
2. **Movimiento con propósito** — cada animación responde a una acción o guía la atención; cero decoración vacía
3. **Contraste extremo** — el rojo se reserva para lo que importa; el negro profundo hace que todo destaque
4. **Velocidad percibida** — transiciones rápidas (150-220ms), scroll fluido, cero lag aparente
5. **Atmósfera dark-room** — como usar el setup de noche: todo vive en oscuridad, los acentos brillan
